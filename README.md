# منصة جمعية منشأ منتوجات الزيتون

نسخة عربية RTL متعددة الصفحات، متجاوبة مع الهاتف والحاسوب، بألوان الأخضر الزيتوني والذهبي، مع إدراج شعار الجمعية المرفق.

## الصفحات
- `index.html` الرئيسية
- `about.html` من نحن
- `services.html` خدمات الجمعية
- `activities.html` الأنشطة واللقاءات
- `news.html` الأخبار والمستجدات
- `gallery.html` معرض منتوجات المنخرطين
- `join.html` طلب الانخراط
- `member.html` فضاء المنخرط
- `contact.html` اتصل بنا
- `admin.html` لوحة الإدارة

## ربط Supabase
1. أنشئ مشروعاً جديداً في Supabase.
2. افتح SQL Editor ونفّذ كامل محتوى `supabase-schema.sql`.
3. من Project Settings > API انسخ Project URL و`anon public key`.
4. ضع القيمتين في أول ملف `app.js` مكان `YOUR_SUPABASE_URL` و`YOUR_SUPABASE_ANON_KEY`.
5. من Authentication > Users أنشئ حساب المسؤول بالبريد الإلكتروني والرقم السري الذي تختاره.
6. بعد إنشاء الحساب، نفّذ في SQL Editor الأمر التالي مع تعويض البريد:

```sql
update public.profiles
set role = 'super_admin'
where id = (select id from auth.users where email = 'ADMIN_EMAIL');
```

7. أنشئ حسابات المنخرطين من Authentication؛ تُنشأ ملفاتهم تلقائياً بدور `member`.
8. يتضمن ملف SQL إعداد جدول `member_products` وسياسات الحماية ومخزن الصور `gallery-products` (5MB، JPG/PNG/WEBP). إذا كان المخطط الأساسي قد نُفّذ سابقاً، نفّذ الملف المستقل `gallery-migration.sql` فقط.
9. بعد الربط، يضيف المنخرط منتوجه من «فضاء المنخرط»، وتبقى حالته «في انتظار المراجعة» حتى تصادق الإدارة عليه من تبويب «منتوجات المعرض». لا يظهر للعموم إلا المنتوج المصادق عليه.
10. انشر محتويات المجلد على GitHub ثم اربط المستودع بـ Vercel. لا يحتاج الموقع إلى إعداد بناء خاص؛ مجلد الجذر هو مجلد النشر.

## الأمان
- لا يوجد اسم مستخدم أو رقم سري افتراضي داخل ملفات الموقع.
- تسجيل الدخول يتم عبر Supabase Auth.
- صلاحية الإدارة مرتبطة بحقل `profiles.role`، ولا يكفي امتلاك حساب عادي لدخول لوحة الإدارة.
- مفاتيح `service_role` ممنوع وضعها في `app.js` أو أي ملف يصل إلى المتصفح.
- سياسات RLS في ملف SQL تقصر قراءة الطلبات والرسائل وإدارة المحتوى على حسابات الإدارة.

## بيانات يلزم استكمالها قبل الإطلاق الرسمي
- عنوان مقر الجمعية.
- رقم الهاتف الرسمي.
- البريد الإلكتروني الرسمي.
- بيانات التأسيس وأعضاء المكتب عند توفر الصيغة المصادق عليها.

## ملاحظة
تعمل الواجهة كصفحات مستقلة حتى قبل ربط Supabase، لكن إرسال الطلبات والرسائل وتسجيل الدخول ولوحة الإدارة تحتاج إعداد Supabase وفق الخطوات أعلاه.
