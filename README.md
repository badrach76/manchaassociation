# منصة جمعية منشأ منتوجات الزيتون

نسخة عربية RTL متعددة الصفحات، متجاوبة مع الهاتف والحاسوب، بألوان الأخضر الزيتوني والذهبي، مع إدراج شعار الجمعية المرفق.

## الصفحات
- `index.html` الرئيسية
- `about.html` من نحن
- `services.html` خدمات الجمعية
- `activities.html` الأنشطة واللقاءات
- `news.html` الأخبار والمستجدات
- `gallery.html` معرض منتوجات المنخرطين
- `join.html` طلب الانخراط
- `member.html` فضاء المنخرط
- `contact.html` اتصل بنا
- `admin.html` لوحة الإدارة

## ربط Supabase
1. أنشئ مشروعاً جديداً في Supabase.
2. افتح SQL Editor ونفّذ كامل محتوى `supabase-schema.sql`.
3. من Project Settings > API انسخ Project URL و`anon public key`.
4. ضع القيمتين في أول ملف `app.js` مكان `YOUR_SUPABASE_URL` و`YOUR_SUPABASE_ANON_KEY`.
5. من Authentication > Users أنشئ حساب المسؤول بالبريد الإلكتروني والرقم السري الذي تختاره.
6. بعد إنشاء الحساب، نفّذ في SQL Editor الأمر التالي مع تعويض البريد:

```sql
update public.profiles
set role = 'super_admin'
where id = (select id from auth.users where email = 'ADMIN_EMAIL');
```

7. أنشئ حسابات المنخرطين من Authentication؛ تُنشأ ملفاتهم تلقائياً بدور `member`.
8. يتضمن ملف SQL إعداد جدول `member_products` وسياسات الحماية ومخزن الصور `gallery-products` (5MB، JPG/PNG/WEBP). إذا كان المخطط الأساسي قد نُفّذ سابقاً، نفّذ الملف المستقل `gallery-migration.sql` فقط.
9. بعد الربط، يضيف المنخرط منتوجه من «فضاء المنخرط»، وتبقى حالته «في انتظار المراجعة» حتى تصادق الإدارة عليه من تبويب «منتوجات المعرض». لا يظهر للعموم إلا المنتوج المصادق عليه.
10. انشر محتويات المجلد على GitHub ثم اربط المستودع بـ Vercel. لا يحتاج الموقع إلى إعداد بناء خاص؛ مجلد الجذر هو مجلد النشر.

## الأمان
- لا يوجد اسم مستخدم أو رقم سري افتراضي داخل ملفات الموقع.
- تسجيل الدخول يتم عبر Supabase Auth.
- صلاحية الإدارة مرتبطة بحقل `profiles.role`، ولا يكفي امتلاك حساب عادي لدخول لوحة الإدارة.
- مفاتيح `service_role` ممنوع وضعها في `app.js` أو أي ملف يصل إلى المتصفح.
- سياسات RLS في ملف SQL تقصر قراءة الطلبات والرسائل وإدارة المحتوى على حسابات الإدارة.

## بيانات يلزم استكمالها قبل الإطلاق الرسمي
- عنوان مقر الجمعية.
- رقم الهاتف الرسمي.
- البريد الإلكتروني الرسمي.
- بيانات التأسيس وأعضاء المكتب عند توفر الصيغة المصادق عليها.

## ملاحظة
تعمل الواجهة كصفحات مستقلة حتى قبل ربط Supabase، لكن إرسال الطلبات والرسائل وتسجيل الدخول ولوحة الإدارة تحتاج إعداد Supabase وفق الخطوات أعلاه.


## ترقية المنصة - فضاء جمعوي متكامل

### الملفات الجديدة
- `upgrade-platform.sql`: ترقية قاعدة البيانات بإضافة البريد الاختياري في طلب الانخراط، الأخبار المصورة والفيديو، مكتبة الوسائط، الشواهد والجوائز، وبرامج التكوين.
- `supabase/functions/accept-member/index.ts`: وظيفة آمنة لقبول طلب الانخراط وإنشاء حساب عبر دعوة بريد إلكتروني دون كشف كلمة المرور.
- لوحة الإدارة: تبويبات الأخبار والأنشطة، منتوجات المعرض، التأطير والتكوين، مكتبة الوسائط، الشواهد والجوائز، والرسائل.

### خطوات التفعيل
1. نفّذ `supabase-schema.sql` إذا لم تكن قاعدة البيانات قد أُنشئت بعد.
2. نفّذ `gallery-migration.sql` فقط إذا كان المخطط الأساسي موجوداً ولم يكن جدول المعرض قد أُنشئ.
3. نفّذ `upgrade-platform.sql` بعد المخطط الأساسي.
4. في Supabase Storage تأكد من إنشاء المخازن التي ينشئها SQL: `gallery-products` و`association-media`.
5. انشر وظيفة `accept-member` باستخدام Supabase CLI:
   `supabase functions deploy accept-member`
6. أضف أسرار الوظيفة في Supabase Functions Secrets: `SUPABASE_URL` و`SUPABASE_ANON_KEY` و`SUPABASE_SERVICE_ROLE_KEY`. لا تضع مفتاح service_role في ملفات الموقع أبداً.
7. في Authentication > URL Configuration أضف نطاق الموقع المنشور إلى Site URL وRedirect URLs حتى يعمل رابط الدعوة وتعيين كلمة المرور.
8. أنشئ حساب المسؤول الأول من Supabase Auth ثم امنحه دور `super_admin` عبر SQL كما هو موضح أعلاه.
9. ضع Supabase URL وanon public key فقط في أول `app.js` ثم انشر المشروع.

### قبول المنخرط وإشعار واتساب
- يجب أن يتضمن الطلب بريداً إلكترونياً صحيحاً حتى يمكن إنشاء الحساب وإرسال دعوة آمنة لتعيين كلمة المرور. البريد اختياري في الاستمارة؛ عند غيابه يمكن قبول الطلب إدارياً دون إنشاء حساب، أو طلب البريد من صاحبه لاحقاً.
- عند اختيار «قبول وإنشاء حساب» تتحقق Edge Function من صلاحية المسؤول، ثم تنشئ حساباً وترسل دعوة آمنة إلى البريد الإلكتروني.
- بعد نجاح العملية يفتح رابط WhatsApp برسالة جاهزة إلى رقم صاحب الطلب. هذه خطوة يدوية يضغط فيها المسؤول على إرسال. الإرسال الآلي الكامل يتطلب WhatsApp Business Platform أو مزود API رسمي معتمد وقوالب رسائل وموافقة المستلمين؛ تطبيق WhatsApp العادي لا يتيح إرسالاً آلياً موثوقاً من الموقع.

### ملاحظات
- روابط الفيديو الخارجية مدعومة في الأخبار ومكتبة الوسائط والتكوين.
- رفع الملفات في مكتبة الوسائط محدود بـ 15 ميغابايت، والصيغ المسموح بها صور JPG/PNG/WEBP وPDF.
- خصائص التكوين تتضمن فئة مستهدفة؛ يمكن اختيار الفئة المهنية عند إضافة كل مادة.
- راجع سياسات RLS واختبر حساب مسؤول وحساب منخرط وحساب زائر قبل الإطلاق.


## ملف SQL الموحد القابل لإعادة التنفيذ
- استخدم `supabase-schema-idempotent.sql` بدلاً من تشغيل `supabase-schema.sql` و`gallery-migration.sql` و`upgrade-platform.sql` كلٌّ على حدة عند إعداد قاعدة جديدة أو تحديث قاعدة موجودة.
- الملف ينشئ الجداول الناقصة، ويضيف الأعمدة الناقصة، ويعيد إنشاء السياسات المعروفة بعد حذفها بالاسم نفسه، ولا يحذف سجلات الجداول.
- عند تشغيله على قاعدة موجودة، خذ نسخة احتياطية أولاً، ثم نفّذه مرة واحدة من SQL Editor.
- لا تشغّل ملفات SQL القديمة بعده إلا إذا كان هناك تعديل محدد موثق يتطلب ذلك.

## مكتبة الوسائط الموحدة

تم تحديث لوحة الإدارة لتوحيد اختيار الصور والفيديوهات والوثائق من مكتبة المنصة أو استيرادها مباشرة من مكتبة الهاتف. تُحفظ الملفات في Supabase Storage ضمن الحاوية `association-media`، وتُسجل بياناتها في جدول `media_library`.

قبل استعمال الميزة لأول مرة، نفّذ ملف `MEDIA_LIBRARY_SETUP.sql` من Supabase Dashboard عبر SQL Editor. يتطلب ذلك وجود جدول `profiles` وعمود `role` بالقيمتين `admin` أو `super_admin` كما هو معتمد في تسجيل دخول الإدارة. اجعل ملفات الوسائط عامة للقراءة، بينما الرفع والحذف محصوران في حسابات الإدارة.

تدعم المكتبة الصور والفيديوهات وملفات PDF، والحد الأقصى لحجم الملف الواحد 100 ميغابايت. اختر الوسائط من مكتبة المنصة داخل نماذج الأخبار والأنشطة والتكوين والشواهد، أو استوردها من الهاتف مباشرة من نافذة الاختيار.


## إقرار الانخراط والوثائق القانونية
- أضيف إقرار إلزامي في نهاية استمارة الانخراط، ويتطلب موافقة صريحة قبل الإرسال.
- تحفظ قاعدة البيانات قيمة الموافقة ورقم نسخة نص الإقرار في حقلي `privacy_consent` و`consent_text_version`.
- قبل النشر، شغّل `MEMBERSHIP_CONSENT_MIGRATION.sql` في Supabase SQL Editor.
- صفحة `documents.html` تعرض القانون الأساسي المرفق وتتيح قراءته وتحميله.
- دفتر التحملات له موضع مستقل في الصفحة، لكنه ينتظر إرفاق النسخة المعتمدة؛ لم يكن موجوداً ضمن الملف الذي تم التوصل به.

## تحسين قبول طلبات الانخراط وعرض الصور

- عند اختيار «قبول وإنشاء حساب»، ينشئ مسار `accept-member` الحساب ويرسل رابط تفعيل/تعيين كلمة المرور إلى البريد الإلكتروني المسجل. بعد نجاح العملية تُفتح رسالة واتساب جاهزة على رقم المنخرط بعد تحويل الرقم المغربي المحلي إلى الصيغة الدولية `212`.
- يلزم على المشرف الضغط على «إرسال» داخل واتساب. لا يستطيع رابط `wa.me` إرسال الرسالة تلقائياً. للإرسال الآلي دون تدخل المشرف، يجب ربط WhatsApp Business Platform (Cloud API) أو مزود معتمد، مع إعداد رقم مرسل موثق ورمز وصول وقالب رسالة معتمد على الخادم. لا تُرسل كلمة مرور سرية ثابتة في رسالة واتساب؛ رابط التفعيل يسمح للمنخرط بإنشاء كلمة مروره بنفسه.
- عُدلت قواعد الصور لتعرض الصورة كاملة دون اقتطاع في الأخبار والأنشطة ومعرض المنتوجات ومكتبة الوسائط والمعاينات الإدارية، مع خلفية محايدة للحفاظ على وضوح الصور ذات الأبعاد المختلفة.
